# 当前展示分数的性能测量

在产品根目录使用 Node 22 和已安装的依赖，参数与命令见[英文说明](README.md)。完整测量通过机器的重任务信号量执行。
数据库地址、数据库名、代码目录和一次性容器名均显式传入；拒绝生产端口。数据库名必须以
`jobradar_test_scoreperf_` 开头，并通过环境变量指定测试配置和已解析的 DE 市场画像。

一年种子为 40000 岗位、410 天；较小种子为 3000 岗位、45 天。写入基线与迁移并发测量使用迁移前模板，
读查询的新旧实现使用同一个已迁移数据库。每个写场景复制独立数据库，分五批执行真实提交，结束后删除副本。
单次打分每批二十次，批量场景每批一次提交；占满桶的场景另外采样同时打分延迟与数据库等待事件。
结果 JSON 和刷新执行计划存入 `/tmp/current-scores-*`。种子均为虚构数据，不导入生产或个人资料。
