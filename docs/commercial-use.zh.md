# 在组织里使用 Job Radar

[English](commercial-use.md) | [中文](commercial-use.zh.md)

Job Radar 是单用户工具，采用 [AGPL-3.0](../LICENSE) 许可。本页回答公司、招聘团队或职业顾问常问的问题。这是工程上的说明，**不构成法律意见**；
事关重大时请咨询你自己的律师。

**公司可以内部原样运行吗？** 可以。自己用，或给组织内部的同事用一份未修改的副本，除了保留许可证和版权声明（[NOTICE](../NOTICE)），没有额外义务。

**如果我们改了代码呢？** 只要其他人（包括员工、客户或委托人）通过网络使用你修改后的版本，AGPL（第 13 条）要求你向这些用户提供你那个版本的完整源代码。
侧栏显示版本号和"源代码"链接；在你自己的 fork 里，把 `package.json` 的 `repository.url` 改成你的 fork 地址即可。只在自己机器上自用的改动不需要公开。

**几个人可以共用一个实例吗？** 不行，它不是为此设计的。没有账号，用户之间也没有认证：能打开网页的人就能看到、修改唯一的一份画像、所有申请和备注。
请**一人一个实例**（各自的代码目录和数据目录，见运维指南），并让每个实例只有它的主人能访问。

**可以做成托管服务提供给别人吗？** 只要向用户提供你那个版本的源代码，AGPL 允许；但架构上没有用户之间的数据隔离，下面说到的抓取和 AI 提供方条款也都要你自己负责。
请按"每个客户一个隔离的实例"来规划。

**抓取其他网站。** 部分通道读取招聘网站的页面，而这些网站的条款禁止自动访问（见 [sources.zh.md 的抓取一节](sources.zh.md#抓取)）。这些通道默认关闭。
公司从公司网络大规模这样做，风险比个人每天在家里做一次高。请优先用官方 API、公司招聘页和你自己的职位提醒邮件。

**AI 订阅。** `codex` 和 `claude` 命令行用的是安装它们的那个人的个人登录。消费者订阅（ChatGPT、Claude Pro 或 Max）是个人许可；
用它们给多个人提供服务，或放进公司部署，可能不在其条款允许范围内。组织使用请改用商业协议下的 API key。请查看各提供方当前的条款，发给它们的内容见 [privacy.zh.md](privacy.zh.md)。

**商标。** Job Radar 与 LinkedIn、Indeed、StepStone、XING、Google、Anthropic、OpenAI、Telegram 以及它能连接的其他服务均无关联；这些名称归各自所有者。

**无担保。** 软件按现状提供，具体条款见许可证。
